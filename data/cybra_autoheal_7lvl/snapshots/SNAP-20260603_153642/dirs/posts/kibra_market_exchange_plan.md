## AI tasks

- `KIBRA-MINT-001` / `finance_infrastructure_task` — Prepare real KIBRA token mint readiness → Підготувати реальний mint-пакет: supply, owner/pool allocation 60/40, metadata, authority policy, manual wallet signature.
- `KIBRA-POOL-001` / `token_pool_ai_task` — Prepare real KIBRA liquidity pool readiness → Підготувати liquidity pool proposal: 60% owner / 40% pool, стартова ліквідність, ризики, slippage, manual approval.
- `KIBRA-PRICE-001` / `monetization_department_task` — Build KIBRA market price engine → Створити модель ціни: не фейкова ціна, а oracle/DEX/CEX/liquidity based price після появи реального ринку.
- `KIBRA-BUYERS-001` / `monetization_department_task` — Build compliant buyers and volume strategy → Створити план попиту: utility, сервіс-каталог, proof certificates, AI task credits, без wash trading і без pump.
- `KIBRA-SELL-001` / `finance_department_task` — Build sell-without-crash model → Створити модель продажу без обвалу: depth, slippage, daily volume limit, TWAP/manual staged sells.
- `KIBRA-APPROVAL-001` / `owner_orchestrator_task` — Create manual OWNER approval package → Підготувати manual OWNER approval для mint/pool/exchange/anchor, без автоматичного виконання.
- `KIBRA-EXCHANGE-001` / `kibra_market_exchange_task` — Design CYBRA own exchange architecture → Створити архітектуру власної біржі: orderbook, AMM, wallet/custody policy, KYC/AML/legal, risk, matching engine sandbox.
- `KIBRA-EVO-001` / `evolution_deployment_task` — Run KIBRA market evolution deployment → Підштовхнути систему до розвитку: mint readiness, pool readiness, exchange readiness, monetization, proof, audit.
